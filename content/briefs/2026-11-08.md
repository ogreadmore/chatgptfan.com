In a desktop test published November 5, Check Point researchers got a ChatGPT conversation to send private text to their server. Lockdown Mode was on, and the person using the app never had to approve the transfer. OpenAI told the team on September 18 that it had fixed the flaw. The team tested again and confirmed the fix. The disclosure documents a demonstration. It doesn’t establish that anyone stole a customer’s chats. [Check Point’s technical report](https://research.checkpoint.com/2026/chatgpt-lockdown-mode-bypass-phishing-malware-delivery-and-silent-data-exfiltration/)

## How a preview became an exit

ChatGPT can show what a piece of HTML will look like when it runs. Ordinarily that preview lives in a sandbox, a part of the app with limited permissions. Ask the preview to open an outside address and ChatGPT can intercept the request. But a window opened from inside another frame in the preview escaped that check. In the desktop app the researchers tested, that window could open without a click. A separate demonstration displayed a fake software update inside a window bearing ChatGPT’s icon. Downloading the file in that desktop example still took a click. [Researchers’ demonstrations](https://research.checkpoint.com/2026/chatgpt-lockdown-mode-bypass-phishing-malware-delivery-and-silent-data-exfiltration/)

OpenAI closed the route by removing the preview’s permission to open those pop-ups. A more obedient model would have left the same window available. That distinction matters for anyone testing an assistant that can display documents, run code or call other services. Try the task in the application people actually use, with the permissions they actually have. [Cloud Security Alliance’s analysis](https://labs.cloudsecurityalliance.org/research/csa-research-note-chatgpt-lockdown-mode-bypass-20261106-csa/)

## Before you upload a sensitive file

Suppose you want help finding a cancellation clause in a contract. Can you ask the question with just that clause and the relevant definitions? If so, you can leave the signature page, bank details and the client’s name out of the conversation. Deciding what the assistant needs is a precaution you control even when its software has a bug. [EFF’s guide to privacy in AI tools](https://ssd.eff.org/module/privacy-considerations-with-ai-tools)

For eligible personal accounts, Lockdown Mode is under **Settings → Security → Advanced security**. It restricts outgoing connections, including live browsing, and disables deep research. A malicious instruction in an uploaded document can still influence an answer. Check a quoted clause against the original before acting on it. If your concern is whether your chats can be used for model training, that choice lives separately in Data Controls. [OpenAI’s Lockdown Mode guide](https://help.openai.com/en/articles/20001061-lockdown-mode)
