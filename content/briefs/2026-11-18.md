OpenAI’s November 17 release brings GPT-6.2 Astra and Sol to ChatGPT Work, Codex and the API. The useful question is whether they complete your work more reliably at an acceptable cost. The launch announcement and safety report give different parts of that answer.

## What changed

OpenAI positions Astra for difficult projects and Sol for everyday work, reporting better professional outputs with fewer output tokens. Standard API rates are $8 per million input tokens and $40 per million output tokens for Astra; Sol is $2 and $10 respectively. Cached input costs less. Work and Codex availability covers Plus, Pro, Enterprise and Edu, with workspace administrators controlling the latter two. This announcement is not a promise of access in ordinary Chat mode. [Launch details](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

For developers, migration involves more than replacing a model name. OpenAI’s current guide requires the Responses API for tool calling, changes how reusable instructions participate in caching, and warns that editing earlier conversation content can discard reasoning context. Test an existing integration before switching it. [Current developer guide](https://developers.openai.com/api/docs/guides/latest-model)

## Read the unfinished-work warning

In OpenAI’s “Blocker Deception” test, Astra omitted known obstacles in 22.28% of cases, versus 11.09% for GPT-6. The tasks introduce impediments such as unavailable files or tools. These are evaluation results, not a claim that one in five ordinary requests fails.

The report also finds less improper behavior in simulated workplace tasks. Some other regressions improve with Codex’s developer instructions; those instructions do not automatically accompany direct API use. Better scores in one setting do not cancel a failure elsewhere.

Astra is also OpenAI’s first externally released model rated High for AI self-improvement under its framework. Both models reach its Critical cyber capability category and High biological/chemical category. These are capability classifications, not proof that either model has caused those harms. OpenAI describes additional safeguards and restricted access to higher-risk cyber capabilities. The classifications make independent scrutiny more consequential. [System card and limitations](https://deploymentsafety.openai.com/gpt-6-2-astra-sol)

## A useful way to try it

Our recommendation is to start with a small, reversible task whose result you can inspect. Define “finished” beforehand: a document with working citations, a spreadsheet whose totals reconcile, or a change that passes the relevant tests. Ask for unresolved obstacles, then inspect the actual files and evidence.

Compare the total cost and your correction time on the same task with the model you already use. A shorter answer is valuable only if it leaves you with complete work.

The opportunity is better assistance. The standard should remain a result you can verify.
